## 1. Domain & Boundary Definition

### What This Document Owns
- Real-time WebSocket JSON-RPC transport implementation in `sizing-watch` using `tokio-tungstenite`.
- Event subscriptions: `newHeads` and `logs` (`Sync` / `Swap` events) across EVM liquidity pools.
- Reconnection management, heartbeat ping/pong, and thread-safe cache invalidation.
- Creation of `sizing-backtest` crate to replay historical tick/block data and benchmark realized alpha against grid search.

### What This Document Does NOT Own
- Sizing mathematical logic (delegates to `sizing-core` and `sizing-router`).
- On-chain transaction execution or mempool broadcasting.

### 2.3 Streaming Architecture & Lifecycle

```mermaid
flowchart TD
    WS[WebSocket Provider Node] -->|JSON-RPC Frames| Reader[Tungstenite Reader Loop]
    Reader -->|Heartbeat Ping| Pong[Pong Frame Response]
    Reader -->|newHeads Event| HeadHandler[Update Current Block Number]
    Reader -->|Sync / Swap Log| LogParser[Decode Reserves & Price]
    LogParser --> Cache[Thread-Safe PoolCache (Arc/RwLock)]
    HeadHandler --> Engine[sizing-watch Engine: evaluate_opportunities]
    Cache --> Engine
    Engine --> Output[Stdout Single-Line JSON OpportunityEvent]
```

### 2.4 Reconnection & Robustness Contract
1. **Exponential Backoff**: If the WebSocket drops, retry after $t = \min(2^k \cdot 250\text{ms}, 10\text{s})$.
2. **Subscription Resumption**: Automatically re-issue `eth_subscribe` for all registered pool addresses upon reconnection.
3. **Graceful Shutdown**: Intercept `SIGINT` / `SIGTERM` via `tokio::signal::ctrl_c()`.

## 3. Historical Backtesting Engine (`sizing-backtest`)

File path: `crates/sizing-backtest/`

### 3.1 Objective
Replays real historical AMM states against an external reference price feed (e.g. CEX 1-second candles) to empirically measure:
1. **Realized Alpha Captured**: Total profit generated by `optimal-sizing` vs. fixed-size baseline and 100-step grid search.
2. **Reverted Transaction Avoidance**: Number of negative-EV trades prevented by exact gas-aware domain restriction.
3. **Execution Latency Savings**: Total CPU time saved by using closed-form and Newton methods over grid search loops.

### 3.2 Historical Data Schema (CSV / JSONL)

```csv
block_number,timestamp_ms,pool_id,curve_type,reserve_0,reserve_1,reference_price,gas_price_gwei
20850100,1728460800000,usdc_weth_uni_v2,cpmm,1250400.50,832.10,0.6651,18.5
20850101,1728460812000,usdc_weth_uni_v2,cpmm,1248000.20,833.80,0.6675,22.0
```

### 3.3 Backtest Output Metrics Report

```rust

}
```

## 4. Acceptance Criteria & Test Contract

1. **Streaming Tests (`sizing-watch`)**:
   - `test_decode_uniswap_v2_sync_log`: Decodes raw ABI log into normalized token decimals.
   - `test_mock_ws_reconnection_loop`: Verifies retry loop reconnects after synthetic connection drop.
2. **Backtesting Tests (`sizing-backtest`)**:
   - `test_backtest_replays_csv_sample_correctly`: Verifies 100% of rows processed with no panics.
   - `test_backtest_confirms_positive_alpha_uplift`: Verifies `optimal_sizing_total_profit_usd` $\ge$ `grid_search_total_profit_usd`.
3. **Execution Command**:
   ```bash
   cargo test -p sizing-watch -p sizing-backtest
   ```
